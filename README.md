# Mnenie ⚖ — суд общества над новостями

**Mnenie** анализирует конфликтные, спорные и резонансные новости и прогнозирует
общественную реакцию: уровень доверия, поляризацию, эмоции, вероятный «вердикт
общества» и динамику изменения мнения во времени.

Система собирает обсуждения из СМИ, соцсетей и форумов, прогоняет их через
NLP/ML-пайплайн (тональность, классификация мнений, выявление ботов,
кластеризация аргументов, анализ источников, прогноз мнения) и показывает всё на
современном минималистичном дашборде.

> Это работающий **MVP**. Полное продуктовое и техническое видение —
> в [`ARCHITECTURE.md`](./ARCHITECTURE.md). Описание API — в [`API.md`](./API.md).

## Возможности

- 📊 **Индекс доверия (0–100)**, % верят / не верят / не определились.
- ⚖ **Суд общества**: итоговый вердикт, уверенность, аргументы большинства и
  меньшинства, разбивка поддерживают/осуждают/фейк/правда.
- 📈 **Динамика мнения во времени** + прогноз модели (пунктир).
- 🧠 **Эмоциональная реакция** (Plutchik), **поляризация общества**,
  **вероятность правды**.
- 🤖 **Выявление ботов и координированных кампаний** (ИПСО).
- 🗺 **Карта распространения мнений** по странам.
- 🧩 **Кластеризация аргументов** сторон, **сравнение источников**.
- 🔥 **Рейтинги** самых спорных и самых поляризующих новостей.
- 🔎 Фильтры по странам, темам, поиску.

## Анализ (как это работает)

Каждый комментарий проходит: нормализацию → определение языка → тональность
(лексикон + отрицания/усилители) → классификацию позиции (верит/не верит/не
определился) → эмоции → бот-скоринг (возраст аккаунта, частота, near-dup) →
тематический кластер. Затем движок (`server/src/analysis/engine.ts`) **взвешивает
мнения** (вес ↓ у ботов и токсичности) и считает индекс доверия, поляризацию,
вероятность правды, вердикт, гео-разрез и временной ряд с прогнозом.

В MVP модели реализованы как интерпретируемые эвристики (RU+EN), чтобы работать
без внешних API и GPU. Места под продакшен-модели (трансформеры, временные ряды,
GNN) помечены `[PROD]` в коде и `ARCHITECTURE.md`.

## Запуск

Требуется Node ≥ 20.

```bash
npm install            # установит зависимости обоих воркспейсов

# терминал 1 — backend (http://localhost:4000)
npm run dev:server

# терминал 2 — frontend (http://localhost:5173, проксирует /api на backend)
npm run dev:web
```

Открыть <http://localhost:5173>.

### Прочие команды

```bash
npm run seed --workspace=server   # прогнать анализ по всем новостям в консоли
npm test  --workspace=server      # юнит-тесты NLP-движка
npm run build                     # сборка backend + frontend
```

## Стек

- **Backend:** Node 20, Express, TypeScript, in-memory store (схема — `schema.sql`).
- **Frontend:** React 18, Vite, React Router, Recharts.
- **Анализ:** собственный NLP-движок на TypeScript (лексиконы RU+EN).
